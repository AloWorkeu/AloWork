# Project Rules

- The Figma file is the source of truth for the application UI: https://www.figma.com/design/YmXhHSNViRqWRhYjymcyki/Hours---Salary-App-%E2%80%94-UI?t=RjynnQWMjTSiPXFF-0
- Develop one screen at a time.
- Match the Figma closely unless a deviation is explicitly approved.
- No shortcuts for core behavior.
- All implemented functions must work end to end before moving to the next screen.
- Test after every screen before moving to the next screen.
- If something is unclear from the design, inspect the repo/context first and ask only when needed.
